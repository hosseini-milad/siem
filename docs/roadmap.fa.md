# نقشهٔ اجرای SIEM

## پایهٔ فعلی: دریافت و ذخیره

مسیر فعلی: Swagger → FastAPI → اعتبارسنجی → MongoDB → پاسخ و مشاهده از Swagger.

هدف پذیرش: ثبت تکی و گروهی، بازخوانی واقعی داده، فیلتر، صفحه‌بندی و پاسخ روشن برای ورودی و شناسهٔ نامعتبر. احراز هویت و AI در این مرحله وجود ندارند. پس از پذیرش این پایه، اتصال پنل جاری یک کار مستقل است.

## فاز مستقل اول ELK: Logstash

ورود منابع واقعی (ابتدا یک منبع نمونه مثل syslog یا فایل JSON)، parse و نگاشت به قرارداد مشترک رویداد، مدیریت دادهٔ نامعتبر و ارسال به API دریافت. قبل از اجرا باید نوع و نمونهٔ لاگ واقعی مشخص شود. Logstash سرویس اصلی خودش است؛ API و منطق سفارشی با پایتون باقی می‌ماند. تنظیم pipeline با قالب پیکربندی Logstash خواهد بود، نه بازنویسی Logstash با پایتون.

معیار پذیرش: یک لاگ نمونه از منبع تا MongoDB با شناسهٔ قابل پیگیری برسد؛ دادهٔ نامعتبر جدا شود و ارسال مجدد سیاست مشخص داشته باشد.

## فاز مستقل دوم ELK: Elasticsearch

MongoDB منبع اصلی نگهداری باقی می‌ماند. Elasticsearch نمای ایندکس‌شده برای جست‌وجوی سریع است. همگام‌سازی از MongoDB با worker پایتون، شناسهٔ پایدار، checkpoint، retry و امکان بازسازی ایندکس طراحی می‌شود؛ از نوشتن ساده و همزمان در دو دیتابیس پرهیز می‌شود. endpointهای جست‌وجو، وضعیت و درخواست بازسازی از Swagger ارائه می‌شوند. انتخاب change stream نیازمند replica set است و با MongoDB تک‌گرهٔ مستقل فعلی فراهم نیست.

معیار پذیرش: دادهٔ ثبت‌شده قابل جست‌وجو باشد و قطع و وصل سرویس باعث گم‌شدن یا تکرار سند ایندکس نشود؛ تأخیر همگام‌سازی قابل مشاهده باشد.

## فاز مستقل سوم ELK: Kibana

تعریف data view و داشبوردهای حجم رویداد، منابع، سطح خطا و روند زمانی بر اساس Elasticsearch. Kibana مستقیماً از MongoDB نمی‌خواند. عملیات سفارشی backend در Swagger می‌ماند؛ خود Kibana رابط داشبورد مستقل دارد. نسخه‌های Elasticsearch و Kibana باید سازگار و با هم انتخاب شوند.

معیار پذیرش: داشبورد دادهٔ واقعی ایندکس‌شده را با بازهٔ زمانی درست نشان دهد و فیلترها با API جست‌وجو تطبیق کنند.

## پس از این مراحل: برچسب‌گذاری هوشمند

worker مستقل پایتون برای برچسب پیشنهادی، نسخهٔ مدل، امتیاز و بازبینی انسانی. دادهٔ اصلی باید حفظ شود و خروجی مدل جدا ثبت گردد. فعلاً هیچ برچسب یا تشخیص هوشمندی تولید نمی‌شود.
