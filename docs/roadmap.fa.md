# وضعیت و ادامهٔ توسعهٔ SIEM

## پیاده‌سازی‌شده

- ورود JSON تکی/گروهی و CSV، نرمال‌سازی و ویژگی‌های رفتاری.
- آموزش و ارزیابی CatBoost/LightGBM از دادهٔ استاندارد، نسبت ۶۰/۴۰ و حذف دو ویژگی زمانی مستقیم از مدل.
- منوبندی و تگ‌های Swagger، شاخص‌های overview، هشدار، قواعد شمارشی و پروندهٔ رخداد.
- دریافت گروهی تکرارپذیر، جست‌وجو و نمودارهای داخلی بر بستر MongoDB.
- اجرای بومی FastAPI با ماژول‌های مجزا برای گردش‌کار عملیاتی.

## مرحله‌های بعد

- اتصال رابط گرافیکی siem-panel به قرارداد منوی API و جایگزینی داده‌های نمایشی.
- scheduler و worker مستقل برای قواعد و آماده‌سازی ورودی مدل؛ اکنون اکشن‌ها دستی‌اند.
- تعیین قالب منابع واقعی و parserهای متن/syslog پیش از توسعهٔ اجنت‌ها.
- ارزیابی مدل روی سناریو/فایل مستقل و انتخاب آستانه با هزینهٔ هشدار اشتباه مشخص.
- تکمیل قواعد هم‌بستگی، مدیریت دارایی، threat intelligence، گزارش‌های تخصصی و response workflow بر اساس نیاز مشخص.
- طراحی احراز هویت و مجوزها در مرحله‌ای که کاربر درخواست کند؛ در نسخهٔ فعلی وجود ندارد.

آماده‌بودن API یا import موفق داشبورد، اثبات ظرفیت تولید، تشخیص حملهٔ ناشناخته یا کامل‌بودن پنل گرافیکی نیست. README راه‌اندازی و محدودیت‌های فعلی را توضیح می‌دهد.
